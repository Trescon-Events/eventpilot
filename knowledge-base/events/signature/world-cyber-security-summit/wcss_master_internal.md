# World Cyber Security Summit Series internal master reference file

## Purpose
This file is an internal reference document for the World Cyber Security Summit Series (WCSS). It is intended to preserve structured, report-derived information from available post-event reports so the material can later be used as knowledge-base input for internal querying across speakers, sponsors, metrics, themes, sessions, audience composition, media performance, and other event intelligence.

## Internal-use status
This file is for internal use only. It is not written for external circulation, publication, or promotional reuse.

## Editorial rules used
- Only uploaded WCSS source reports were used.
- No outside sources were used.
- Missing or weakly readable information was not inferred.
- Where OCR quality was weak, low-confidence details were omitted or noted under Data-quality notes.
- Source filenames are preserved exactly as provided.
- Chronology is preserved.
- Report-specific promotional, media, app, and outreach numbers are recorded as stated in the underlying reports and should not be treated as standardized series-wide measures.
- Event classification has been recorded for each edition as standalone event, combined/co-located report, or umbrella-week report, based only on the supplied reports.

## Coverage in this file
This file currently covers the following available WCSS reports:
- `wcss22-jordan-event-report-2.pdf`
- `wcss-23-jakarta-post-event-report.pdf`

The covered editions are:
- World Cyber Security Summit 2022 Jordan (Amman)
- World Cyber Security Summit 2023 Jakarta

## Interpretation cautions
- Missing editions in this file must not be treated as proof that the series did not run in other years or markets.
- Metrics, speaker counts, partner counts, and outreach numbers come from individual event reports and may reflect different reporting methods across years.
- Session naming conventions and role titles should be interpreted in the context of each edition’s source document.
- Some sponsor blocks in the Jakarta report are visually incomplete in the OCR capture; only clearly recoverable names have been preserved.

## Critical cautions
- This file should be treated as a report-grounded internal extraction, not as a definitive corporate master chronology of every WCSS edition.
- Where OCR introduced uncertainty, the file deliberately stays conservative.
- Any later external-facing narrative should be separately verified against source PDFs before publication.
