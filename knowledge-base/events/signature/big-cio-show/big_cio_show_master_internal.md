# Big CIO Show internal master reference file

## Purpose
This file is an internal master reference for the Big CIO Show series, built from available post-event reports supplied in this workspace. It is structured for future AI retrieval across event history, including speakers, awards, partners, themes, metrics, media activity, and report-specific caveats.

## Internal-use status
Internal working document for knowledge-base and retrieval use only. Not for external publication, publicity, or public claims without edition-level verification.

## Editorial rules used
- Only facts visible in the available source reports have been retained.
- Missing editions in this file must not be treated as proof that the event did not happen.
- Where OCR quality is weak, only high-confidence facts are retained.
- Report-level marketing and media metrics are recorded exactly as stated in each source and are not normalized into a single methodology.
- If a pre-event publicity number appears inside a post-event report, it is labeled as a pre-event claim and not merged into final attendance figures.
- Conflicting or unusual counts are preserved with caution notes instead of being silently corrected.

Covered editions currently extracted from available reports:
- Big CIO Show 2019 Mumbai.

## Interpretation cautions
The series uses varying labels across years, including Big CIO Show, Big CIO Show Awards, edition numbers, and later “global edition” phrasing. Metrics also vary in style and reliability across reports, so figures should be interpreted at the edition level rather than combined into a single cross-year benchmark unless separately validated.

## Critical cautions
- Sponsor quotes and lead figures are sponsor-specific unless the report explicitly states they are event-wide.
- Awards rosters are sometimes extensive; this master file captures the existence and structure of those rosters without reproducing every name unless necessary for retrieval quality.
- Venue, partner, or metric discrepancies have been retained in notes where relevant.
- This file reflects only the post-event reports made available in this thread.
