# World AI Show internal master reference file

## Purpose
This document is an internal consolidated reference for the World AI Show post-event reports processed in this project. It is intended for internal strategy, content development, retrospective analysis, future report generation, and knowledge-base use alongside other Trescon event materials.

## Internal-use status
This file is not intended for public release or external publication. It should be treated as an internal working reference document that captures what is explicitly available from the source reports currently on hand.

## Editorial rules used
- Only factual information explicitly available in the processed source reports has been retained.
- No missing dates, names, titles, metrics or locations have been inferred.
- Combined reports retain only World AI Show-relevant information.
- Inseparable combined-event figures are clearly marked and must not be treated as WAIS-only totals.
- Weak-OCR fields are either omitted or flagged in data-quality notes.
- Long sponsor and media clipping lists are not reproduced unless they materially affect event understanding.
- Promotional and outreach figures are retained only as reported in the available source files and should not be treated as definitive series-wide benchmarks.

## Coverage in this file
This master file includes extracted event coverage only for the WAIS post-event reports that were available and processed in this project.

It does not represent every World AI Show edition that has taken place historically, because not all editions had a post-event report available in the source set used for this consolidation.

The current document includes extracted event coverage for the following reports:
- 2018: Dubai, Singapore, Mauritius (combined WAIS + WBS filtered to WAIS-only), Mumbai (OCR caution)
- 2019: BFSI NBFC India, Bangkok, Dubai, Qatar, Riyadh, Mumbai, Nairobi, Singapore
- 2022: Dubai, Singapore, India (Mumbai), Jakarta, Malaysia virtual (Kuala Lumpur)
- 2023: Dubai MENA, Jakarta APAC, KSA Riyadh (combined DATE AI + FinTech filtered to AI-only relevance), Singapore
- 2024: India (Mumbai)
- 2025: Malaysia (Kuala Lumpur), Indonesia (Jakarta)

## Interpretation cautions
- This document reflects only the information available in the source reports processed here.
- Missing editions in this file should not be interpreted as years or cities where WAIS did not take place.
- Promotional, outreach, media and social figures may vary across reports and over time based on reporting method, scope, campaign period, and what was included in each individual post-event report.
- As a result, these figures should be treated as report-specific reference values rather than standardized franchise-wide totals.

## Critical cautions
- Mauritius 2018 contains combined World AI Show + World Blockchain Summit reporting. Any inseparable headline numbers remain combined-event totals.
- KSA 2023 contains combined DATE AI + FinTech reporting. Any inseparable headline numbers remain combined-event totals.
- Mumbai 2018 was affected by weak OCR in earlier extraction and should still be treated cautiously.
- A few charts in later reports are image-heavy; only clearly readable text-derived figures have been normalized here.
