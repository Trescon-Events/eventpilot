# Future Sustainability Forum internal master reference file

## Purpose
This file consolidates verified information from the two uploaded Future Sustainability Forum post-event reports into a single internal reference document for future AI retrieval. It is limited to facts explicitly supported by the reports.

## Internal-use status
This file is internal-only and not intended for external publication. It is a structured reference extract rather than a public summary.

## Editorial rules used
- Only the two uploaded reports were used.
- No outside sources were used.
- The canonical series name used in this file is Future Sustainability Forum.
- Each edition preserves the original event name as used in its report.
- Exact source filenames are preserved.
- Facts were included only where clearly stated in the reports.
- Low-confidence OCR fragments and unclear items were omitted or moved into data-quality notes.
- If a metric or item appeared report-specific, it is recorded only under that edition and not normalized across the series.

## Coverage in this file
This file covers two documented editions in chronological order:
- Future Sustainability Forum 2023, Dubai
- Future Sustainability Forum 2024, Dubai

## Interpretation cautions
- Missing editions in this file must not be treated as proof the event did not happen outside the scope of these two reports.
- Differences in metrics, terminology, and formatting between editions should be treated as report-specific rather than as standardized series definitions.
- Some pages in the reports are image-led and OCR quality varies, especially for sponsor grids, partner grids, session boards, and some proper names.

## Critical cautions
- Do not infer series history beyond what these two uploaded reports confirm.
- Promotional, media, digital, outreach, and participation figures should be treated as report-specific.
- Where session, partner, or competition details are partially visible but not fully legible, only clearly verifiable items are retained.
